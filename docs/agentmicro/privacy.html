PRIVACY POLICY

AgentMicro keeps task observation on your Mac.

Effective August 9, 2026.

Data collection

AgentMicro does not collect, transmit, sell, or share personal data, task data, analytics, diagnostics, advertising identifiers, or tracking information.

Local data access

AgentMicro reads local Codex session metadata and rollout files to show task state. The Mac App Store edition accesses the Codex data folder only after you select it in the macOS folder picker. That permission is read-only and is stored locally as a security-scoped bookmark. AgentMicro does not upload prompts, responses, source code, command output, task titles, or session files.

Optional Accessibility access

Enhanced Status Detection is off by default. If you enable it, AgentMicro reads a bounded set of visible labels from the focused Codex window to identify the selected task and visible approval or error state. It never clicks, types, approves, or sends accessibility content.

Local preferences

Language, display, onboarding, read-state, folder authorization, and launch-at-login preferences remain on your Mac. Removing the app and its container removes the App Store edition’s stored preferences.

Network access and third parties

The Mac App Store edition does not include AgentMicro’s direct-download updater; Apple delivers its updates through the App Store. The direct-download edition contacts the public AgentMicro release feed on GitHub only to check for software updates. Apple and GitHub process requests under their own privacy policies.

Changes and contact

Material changes will be published on this page and reflected in the policy’s effective date. Questions or privacy reports can be filed in the public AgentMicro issue tracker; do not include private task content or credentials.
