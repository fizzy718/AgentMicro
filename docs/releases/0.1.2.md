# AgentMicro 0.1.2

AgentMicro 0.1.2 improves the recent-task list and introduces the standard macOS drag-to-Applications installation experience.

## Highlights

- Adds a signed and notarized DMG with a guided Finder layout: open the disk image, then drag `AgentMicro.app` onto the Applications folder.
- Keeps the existing signed ZIP as the Sparkle update artifact, so users on 0.1.1 can update from AgentMicro settings.
- Removes explicitly archived Codex tasks from the current task menu.
- Prevents orphaned guardian records from reintroducing an archived parent as a visible task.
- Preserves active Desktop tasks when archive metadata is temporarily unavailable, while expiring ambiguous records after a bounded retention window.

## Installation

Download the DMG, open it, and drag `AgentMicro.app` onto the Applications folder. Launch AgentMicro from `/Applications`.

The ZIP remains available for software updates and manual installation.

## Upgrade note

AgentMicro 0.1.1 can check for and install this release through **Settings → Updates**. Users on 0.1.0 must still replace the app manually because that build cannot reliably start Sparkle.

## Privacy

AgentMicro reads task state locally. It does not upload prompts, responses, source code, command output, or task files.

## Requirements

- macOS 14 or later.
- Codex Desktop or Codex CLI installed locally.
- Universal build for Apple silicon and Intel Macs.
