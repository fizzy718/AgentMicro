# AgentMicro 0.1.1

AgentMicro 0.1.1 is the first release intended for everyday use. It improves task-state accuracy, navigation, settings, localization, and the signed update foundation while keeping all Codex observation local to your Mac.

## Highlights

- Closes unread results from green to white as soon as the exact task is successfully opened through AgentMicro.
- Improves detection of active reasoning, user questions, approval requests, browser handoffs, rate limits, and ordinary execution failures.
- Adds optional Enhanced Status Detection for the task currently selected in Codex and visible approval or error controls. It is disabled by default, never required, and requests macOS Accessibility permission only after explicit opt-in.
- Keeps running tasks at the top and shows each current-turn duration to the second, including the fast-mode indicator when available.
- Adds a compact six-light menu bar status icon, an adaptive layered app icon, and a narrower task menu.
- Adds paged settings, the five-color first-launch guide, configurable task count from 1 to 20, and 23 selectable interface languages plus Follow System.
- Improves task-to-Codex navigation, including sessions whose local rollout identifier differs from the Codex navigation identifier.
- Adds version display, manual update checks, optional automatic update checks, a dedicated Sparkle feed, and AgentMicro-specific signing keys.

## Five task states

- White: idle or already viewed.
- Green: a new result is ready and has not been viewed.
- Blue: Codex is actively working.
- Orange: Codex needs a user answer, approval, or external action.
- Red: the current turn is blocked by an error.

## Privacy

AgentMicro reads task state locally. It does not upload prompts, responses, source code, command output, or task files. Enhanced Status Detection is read-only and never clicks, types, approves, rejects, or sends content.

## Upgrade note

AgentMicro 0.1.0 cannot reliably launch Sparkle, so it cannot update itself to 0.1.1. Download 0.1.1 from this release and replace the previous app manually. Signed releases from 0.1.1 onward contain the production update feed and can participate in subsequent update tests.

## Requirements

- macOS 14 or later.
- Codex Desktop or Codex CLI installed locally.
- Universal build for Apple silicon and Intel Macs.
